## 레슨 타입 분배 (코스당 20개 기준)
- quiz: 8개 (40%) — 객관식, 가장 학습 효과 높음
- flashcard: 5개 (25%) — 용어/개념 암기
- fill_blank: 4개 (20%) — 코드 빈칸 채우기
- reading: 3개 (15%) — 코드 읽기/출력 예측

## 난이도 프로그레션 (코스 내)
- 레슨 1-5: 개념 소개 (flashcard 위주)
- 레슨 6-10: 기초 적용 (quiz + fill_blank)
- 레슨 11-15: 심화 문제 (quiz + reading)
- 레슨 16-20: 실전 + 종합 (quiz 위주)
